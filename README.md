# Практическая работа №19

Автор: Кадралиева Аделина
Группа: ИСП-251

Тема: Строки в C#.

Что реализовано:
- определение длины строки;
- подсчёт букв, цифр, пробелов и слов;
- поиск первого индекса символа;
- удаление пробелов по краям;
- перевод в верхний регистр;
- замена пробелов на подчёркивания;
- дополнительно: подсчёт русских гласных.

Короткие ответы:

1. Чем отличаются string и char?
String это строка, то есть текст в двойных кавычках. А char это один символ в одинарных кавычках.

2. Почему вызов text.Trim() без сохранения результата не меняет text?
Потому что строки в C# неизменяемые. Trim() не меняет старую строку, а возвращает новую. Если её не сохранить, она просто пропадёт.

3. Зачем при разделении строки используется RemoveEmptyEntries?
Чтобы в массиве слов не было пустых элементов. Например, если поставить несколько пробелов подряд, Split без этой настройки сделает пустые слова, а с ней он их пропускает.
